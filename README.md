# Shiksha Sarthi

Shiksha Sarthi is a web-based platform developed for **NMMS (National
Means-cum-Merit Scholarship) exam preparation**. It provides students
with practice and quiz facilities, while teachers can manage questions
and assess student performance.

## Key Features

-   **Student access:** Students can log in and access learning and quiz
    activities.
-   **Question management:** Teachers can manage questions in the
    question bank.
-   **Quiz system:** Students can attempt quizzes and submit their
    answers.
-   **Performance tracking:** Quiz results and student performance can
    be tracked.
-   **Practice modules:** Subject-wise and topic-wise question practice.
-   **Hindi hints:** Gemini API can generate Hindi hints for questions
    when a hint is not provided.
-   **School deployment:** The platform was deployed for use in a real
    school. An offline LAN-based setup was also documented for schools
    with limited internet connectivity.

## Technology Stack

-   **Frontend:** React
-   **Backend:** Node.js, Express.js
-   **Database:** MongoDB, Mongoose
-   **API communication:** Axios
-   **AI integration:** Google Gemini API

## Architecture

The application follows a three-tier architecture:

1.  **Frontend:** React-based interface for students and teachers.
2.  **Backend:** Node.js and Express REST APIs handle application
    operations.
3.  **Database:** MongoDB stores users, questions, quizzes, and
    performance reports.

## Project Context

Developed as a team project during an internship associated with
**Indian Institute of Technology Bhilai**. The platform was successfully
deployed in a real school, where students actively used it.
